Artikelen beheren

Om artikelen rechtstreeks op de site te plaatsen, te bewerken en te verwijderen is eenmalig een GitHub-token nodig. Het token blijft alleen in deze browser en geeft uitsluitend schrijfrecht op de bestanden van deze site.

  1. Ga naar github.com/settings/personal-access-tokens/new, ingelogd als eigenaar van de site.
  2. Token name: dcbs.nl nieuws. Expiration: bijvoorbeeld 1 jaar (daarna hier een nieuw token plakken).
  3. Repository access: Only select repositories, kies dcbs-website.
  4. Permissions, Repository permissions: Contents op Read and write. Klik Generate token en kopieer het token.

Publiceren zet de wijziging direct op de site. GitHub Pages werkt de pagina's binnen 1 tot 3 minuten bij; de lijst hieronder toont meteen de nieuwe stand. Bij elk artikel staan knoppen Bewerken en Verwijderen.
